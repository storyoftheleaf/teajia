# K14 score audit

Read-only audit at build/l4-k0-sharing-fixes 5fb38fd3, 2026-11-26. Rule (Adrian): a score is personal. It is never a public number, star count or average. A host's own live tasting screen is the exception.

**A viewer with no permission bundles received another person's score from three routes in the actual Worker.** With an in-memory database, `GET /api/products`, `GET /api/products/:id`, and `GET /api/tea-reviews?tea_key=K` all returned HTTP 200 and the fixture giver's `8`. The review response returned it twice, as `rating` and `tasting.quality`.

I audited detached revision `5fb38fd38`, which matches the checkout's `origin/build/l4-k0-sharing-fixes`. No files changed and no production requests were made. The remaining findings have fixture reproductions below. Browser reproductions describe the steps established from source. I did not execute them in a browser.

### Averages and counts

21. **Authenticated MCP `get_sample` computes and returns a cross-person average.** An `inventory:read` caller gets `tastings.count`, `by_verdict`, `average_rating`, and `would_buy_count`. The checked-in fixture expects two tastings and an average of `7`. With only one rating of `8`, the average reveals that giver's exact `8`. There is also an arithmetic error when ratings are missing: a verdict group with ratings `[8, null]` and another with `[2]` produces `6.0`; the mean of the two entered ratings is `5.0`. SQL excludes nulls from `AVG`, then JavaScript weights each group by `COUNT(*)`. This tool is on authenticated MCP. [Calculation](worker/src/mcpTools/writing.ts:926) · [Existing fixture](worker/tests/mcp-writing.test.ts:374)

22. **The storefront contains a star-average calculation that its current API contract cannot feed.** With two component input reviews rated `2` and `4` for the same tea, it calculates `3.0`, draws three filled stars, and prints a count of two reviews. In the actual request it supplies visibility alone, which the Worker rejects with 400. It also expects `{reviews:[…]}` while a successful keyed read returns a bare array. I found the calculation, but no working public star display through this path.
