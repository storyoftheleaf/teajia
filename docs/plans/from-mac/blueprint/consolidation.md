## Order and approval

Start with low-risk metadata and archive labeling after confirming ownership. Then reconcile content and documentation authorities. Follow with specific, reversible removal candidates in small commits with a before/after path list and test evidence. During a cleanup, preserve the accepted route, editorial source, fixture and deployment contracts. Production URLs, private originals, licensing and content/approval state each have their own owner.

The recommendation is a consolidation plan. The audit performed no removals, database edits, deployments, source sync, or archive moves. Existing mutable files and predecessor session state remain in their current locations.
