Why it says zero

You are almost certainly right, and for a better reason than the one you gave. Putting the currency back on that column does not just read better. It is what makes this fault visible at all.

That column is in dollars, but the number behind it is stored in each tea's own buying currency. So a tea bought in rupiah with 12 in that column is charging twelve rupiah a kilo, which is a fourteen-thousandth of a cent, which prints as 0.00 and looks like a rounding artefact rather than free freight.

The arithmetic that produces your zero

Take a tea you bought in Bali, priced in rupiah, carrying 12 in the freight column because something wrote 12 there:

Stored on the tea12
Read as, because the column is in the tea's own currencyRp 12 per kilo
Divided by today's rupiah rate÷ 16,300
Which is, per kilo$0.0007
Rounded to two decimals for the column0.00
What it should be, at 85 yuan$11.89

The tea ships free and the column tells you so in a way nobody would read as a warning. Every one of these bugs this week has had that shape: a wrong number that looks like a normal one.

What I found while looking, which is live now

A fifth freight rate, in the import path

curate_import_batches.shipping_rate_per_kg is declared NOT NULL DEFAULT 12.0. Twelve was the old shop rate in dollars, from before freight moved onto the account as 85 yuan. Every Curate import batch is born carrying it, and it is copied onto every tea in that batch, into a column that means the tea's own currency. That is the four-freight-rates bug still running in the one door nobody re-checked, and it is where a 12 comes from.

Because the column is NOT NULL it cannot even record “nobody said”, so the shop rate can never apply to an imported tea.

Why the Y562 still has its dot

Yesterday's migration had two clauses. The second one clears a 1993 tea that is shipping free. If that tea is still pinned after it ran, then the first clause did not match its name and the second did not match its year, which means the Year column on that row is not 1993. Worth a glance while you are there.
