# Walkthroughs

Pages built for Adrian to *look at*, rather than prose or a diff to read. Each
one is published as an artifact; the HTML here is the source, so a later session
can find it, update it, and republish to the same URL.

**To update one:** edit the file here, then republish it with the `Artifact`
tool passing that artifact's `url`. Publishing without the `url` creates a
second artifact at a new address and the link Adrian already has goes stale.

The Y562 page is the worked example the migration rule in `CLAUDE.md` points at:
a migration that moves rows gets a page like that one, and Adrian gets the link,
before it is pushed.

strip across the top) so that a set of them reads as one body of work rather
than as three unrelated pages.
