The token and its scopes

Minting it is yours: the shop shows it once and nobody else can see it, me included. Everything either side of that is now one command.

Three steps, in order

  1. 01

    Mint it, and tick two extra boxes

    www.teajia.com/admin/mcp-tokens, name it something like laptop, and before you press the button tick catalog:write and admin:write. The five ordinary boxes are already ticked; those two are not, and a token cannot be widened afterwards. Copy the token when it appears. It is shown once.

  2. 02

    Put it in Infisical

    In Terminal, in the teajia folder, paste the token in place of the amber part:

    infisical secrets set TEAJIA_MCP_TOKEN=<paste it here> --env=dev --path=/

    That is the same place every other Teajia secret lives. Nothing is written to a file in the repo, and the token never has to be typed again.

  3. 03

    Ask the shop what it can do

    npm run mcp:check

    Prints the connection, the number of tools, and the list of scopes the shop actually grants. It never prints the token.

    After that, start sessions with npm run claude instead of claude. That is the part that hands the token to the session, so a session can go and change a cost itself rather than asking you to.

What each box buys you, and which two are off

ScopeAt mintWhat it lets a sentence do
inventory:readTickedLook up a tea, read stock, read the shop's settings
customers:readTickedFind a customer
sales:readTickedRead invoices and sales totals
stock:writeTickedAdd a tea, move stock, set a price or a freight rate on one tea
sales:writeTickedRaise, fill and void invoices
catalog:writeNot tickedFix a whole vendor's cost currency, publish tasting notes, archive
customers:writeNot tickedCreate and edit customer records
admin:writeNot tickedChange the shop's freight rate and the exchange rates

The trap is that a half-scoped token looks perfect. It connects, it lists tools, it answers questions about the shelf. It just cannot touch a price, and you find that out at the moment you ask it to. That is the whole reason step three prints scopes instead of the word connected.

If step three says something else

The shop refused the token
Revoked, mistyped, or the paste lost its tail. Mint another and redo step two.
Something between here and the shop refused
Not the token. A network is blocking api.teajia.com, which is the normal state of a cloud session until that address is allowed.
This token cannot change a price
catalog:write was left unticked. Mint another with it on; the old one keeps working for everything else, or revoke it.
TEAJIA_MCP_TOKEN is not set
Step two has not run, or it went to a different Infisical project. Run it again from the teajia folder.
I cannot mint this for you and would not want to hold it if I could. The value goes from the shop to your clipboard to Infisical, and from there straight into a session's memory when one starts. It is not in the repo, not in a commit, and not in this chat.
