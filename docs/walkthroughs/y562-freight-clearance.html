The one thing testing caught

I first wrote the year match as text, comparing against '1993'. Run against the seeded database, it matched a year stored as the string and missed one stored as a number, which a driver can land as 1993.0.

That column is text, but three different doors have written it three different ways over the years. A text comparison misses two of them by doing nothing at all, which is the failure that looks exactly like success. It compares as a number now.
