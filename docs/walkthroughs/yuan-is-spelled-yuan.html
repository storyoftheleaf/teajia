What it changes

The shop keeps one exchange table, and yuan sits in it as Yuan. A voice tool was saving the currency in capitals, so some teas ended up labelled CNY or YUAN. The shelf never noticed: the worker knew all three meant the same money and priced them right.

The admin did not know. It looked up CNY, found nothing, and treated the cost as dollars. So the dashboard has been counting the 1993 Y562 at $1,200 instead of $178, the retail preview on those teas has shown a dash, and a freight rate pinned to one of them would have read as $85 a kilo instead of $12.63.

This corrects the spelling on the rows. The code that made them is already fixed and on main, including the admin's own save routes, so the label cannot come back.

It moves

Any tea or piece of teaware whose currency reads CNY or YUAN, in any casing, on the products table and on the partner listings table.

It leaves alone

Everything already spelled Yuan. Everything in HKD, NT, USD, IDR, JPY, MYR or AUD. Every tea whose currency nobody ever stated. Every cost amount. Every stated-or-not mark.

What it touches, and what it leaves alone
