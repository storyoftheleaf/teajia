# Store Launch Playbook

The operator-facing launch playbook now lives in the product UI.

- Public page: `/store-launch-playbook`
- Admin page: `/admin/launch-playbook`

Use the public page before a store has access. It lets an owner or operator plan the store profile, staff, opening stock, first customer flow, and optional first event.

Use the admin page after the account exists. It pre-fills what it can from the active account and links each step to the place where the real setup is saved.

The static docs remain useful for internal review, but the web playbook is the source of truth for onboarding any new store.
