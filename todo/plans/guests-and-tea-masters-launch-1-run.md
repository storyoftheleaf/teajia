# First table and the guest’s Tea Chest

The after-sit thank-you keeps the session and the teas together. A guest can keep a tea from the thank-you with zero grams and an unstated cost. A buyer can keep a bought tea once per order line. Tapping again must return the existing holding. The source session stays attached to the first action.
