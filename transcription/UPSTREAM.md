# Upstream review and provenance

Reviewed upstream implementation code on 2026-10-04 before choosing the adapters. No application source has been vendored or copied into this package; model inference and word alignment are calls to the maintained libraries. The stdlib checkpoint/output orchestration and reconciliation are specific to this integration.

| Upstream | Code reviewed | License / integration decision |
| --- | --- | --- |
| [weypro/whispermlx](https://github.com/weypro/whispermlx) | `whispermlx/asr.py`, `diarize.py`, `transcribe.py` | BSD-2-Clause, Max Bain. MLX wrapper resolves full large-v3, VAD chunks and WhisperX forced alignment. Its wrapper disables native word timestamps; use official mlx-whisper directly to keep native words without its larger stack. |
| [haniabdemai/local-transcription](https://github.com/haniabdemai/local-transcription) | `process_lesson.py`, `diarize.py` | MIT, Hania B. Demai. Useful separation of normalization/ASR/diarization/merge and preloaded waveform. Its defaults force English and turbo; its merge drops words. This integration uses full large-v3, automatic language, retained words and splits speakers at word boundaries. |
| [sblattj/whosaid](https://github.com/sblattj/whosaid) | `lib/diarize_sherpa.py` | MIT, Stephen Blatt. Useful local artifacts and atomic sidecar writes; uses sherpa-onnx segmentation/embedding models rather than Community-1. Voice enrollment/search/watch/app machinery is outside this package. |
| [m-bain/whisperX](https://github.com/m-bain/whisperX) | `whisperx/diarize.py`, ASR orchestration | BSD-2-Clause, Max Bain. Reviewed summed temporal-overlap speaker attribution and no-nearest-fill behavior. The integration follows that policy with its own small stdlib reconciliation; no pandas or WhisperX import required. |
| [sooth/whisperx-mlx](https://github.com/sooth/whisperx-mlx) | `src/whisperx_mlx/backends/mlx_whisper.py`, `transcribe.py`, `diarization/pyannote_backend.py` | Declares BSD-2-Clause in pyproject/README; no root LICENSE seen in source tree. Its cached/batched ASR and forced aligner are potential later research. Reviewed pyannote backend defaults to 3.1, uses old auth API and can silently return no turns after errors; do not import that backend for Community-1. |
| [Apple mlx-whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper) | `mlx_whisper/transcribe.py` | MIT, Apple. Direct library dependency. Native cross-attention/DTW word timestamps via `word_timestamps=True`; automatic recording language via `language=None`. Explicit model overrides its upstream turbo default. |
| [pyannote Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) | Official model card and documented 4.x `Pipeline.from_pretrained`, in-memory input, progress hook and exclusive diarization | Community-1 weights: CC-BY-4.0; pyannote.audio library: MIT. Attribution: pyannote, Alexis Plaquet and Hervé Bredin (segmentation), WeSpeaker contributors (embeddings), and VBx authors (clustering), as cited on the model card. Requires user acceptance of gated Hugging Face conditions and a read token for initial download. Inference stays local; optional pyannote telemetry disabled. |

Model repositories are selected by repository/path, so downloaded upstream revisions may change. Use local model directories and retain their downloaded revision records when exact reproducibility is required. Underlying weights have their own licenses independent of wrapper licenses. No paid inference service is used.
